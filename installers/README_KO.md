# 3.1.5 설치

Rhino를 모두 종료한 뒤 BKID_AutoCrop_SixView_Setup_3.1.5.exe를 실행하고 Rhino Installer에서 현재 사용자 설치를 완료하세요. 기존 BKID AutoCrop은 그대로 유지하고 BKID_AutoCrop_SixView를 별도로 설치합니다.

기존 BKID_AutoCrop_SixView 재설치에 동의한 경우에만 BKID_AutoCrop_SixView 파일을 교체합니다. AutoCrop은 삭제하지 않습니다. 새 설치가 실패하거나 취소되어도 이전 버전은 자동 복원되지 않습니다. 모델·저장 PNG는 삭제하지 않습니다.

설치 후 좌클릭은 1배로 6뷰 저장, 우클릭은 ×2·×3·×4 배율과 폴더 설정입니다. 자세한 사용법과 실제 Rhino 미검증 범위는 루트 README.md를 참고하세요.
