# 3.0.0 설치

Rhino를 모두 종료한 뒤 BKID_AutoCrop_Setup_3.0.0.exe를 실행하고 Rhino Installer에서 현재 사용자 설치를 완료하세요. 기존 BKID AutoCrop을 교체합니다. 별도 공존 설치가 아닙니다.

기존 설치 삭제에 동의하면 삭제 후 새 패키지를 설치합니다. 새 설치가 실패하거나 취소되어도 이전 버전은 자동 복원되지 않습니다. 모델·저장 PNG는 삭제하지 않습니다.

설치 후 좌클릭은 1배로 6뷰 저장, 우클릭은 ×2·×3·×4 배율과 폴더 설정입니다. 자세한 사용법과 실제 Rhino 미검증 범위는 루트 README.md를 참고하세요.
