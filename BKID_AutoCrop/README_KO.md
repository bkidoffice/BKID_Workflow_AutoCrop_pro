# AutoCrop 6 Views 캡처 엔진

권장 설치는 저장소 루트 `installers/BKID_AutoCrop_Setup_3.0.0.exe`입니다. 사용법·출력 규칙·검증 상태는 루트 README.md를 참고하세요.

이 폴더의 BKID_AutoCrop.py는 Windows Rhino 6/8 IronPython 2.7용이며 RunPythonScript로 실행할 수 있습니다. 플러그인은 이 파일을 내장해 배율·저장 폴더를 전달합니다. 좌클릭은 1배, 우클릭은 ×2·×3·×4입니다. 선택 객체 또는 보이는 모델 전체를 표준 6뷰 PNG로 저장합니다.

Install_RunAutoCrop.py와 Show_AutoCrop.py는 과거 Python 설치 경로의 호환 코드입니다. 3.0.0의 권장 툴바와 배율 UI는 EXE/RHI의 네이티브 플러그인에 있습니다.
